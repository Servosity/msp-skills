# Trademarks and Vendor Non-Affiliation

## msp-skills is unofficial

`msp-skills` is a community open-source project maintained by Servosity Inc.
It is **not affiliated with, endorsed by, or sponsored by** any of the
third-party software vendors whose APIs are wrapped by Claude Code Skills,
MCP servers, or other tools in this repository.

All third-party product names, logos, and trademarks are property of their
respective owners. Skills and MCP servers in this repository reference vendor
names solely under nominative fair use to indicate API compatibility.

## Vendors referenced in this repository

The skills currently shipped in this repository wrap APIs from the following
vendors. Each is independent of `msp-skills` and Servosity Inc.

| Vendor | Trademark holder |
| --- | --- |
| HaloPSA, HaloITSM, HaloCRM | Halo Service Solutions Ltd. |
| Servosity | Servosity Inc. |

This list grows as new skills land. The CI workflow `catalog.yml` regenerates
it from each skill's `manifest.json` on every PR that touches `skills/`.

## Servosity and Compounding Teams

"Servosity" and "Compounding Teams" are trademarks of Servosity Inc. They may
be referenced descriptively in contributed skills and documentation. They may
not be used in skill names, marketing copy, fork branding, or anywhere that
would imply endorsement of a contributor's work by Servosity Inc.

## Reporting concerns

If you are a rights holder and believe a skill in this repository misuses your
trademark or implies an affiliation that does not exist, open an issue and we
will respond within five business days. Skills found to misuse trademarks will
be reworded or removed.
