# Build Sessions: connectors built live, every Thursday

**Build Sessions are free, every Thursday.** Bring your tenant and your hardest cross-client question and watch a connector built and run against a real MSP system live - or just watch and ask. It's where the next connectors on this site get made, with real MSPs in the room driving them against their own production tools. [Join the next free Build Session →](https://compoundingteams.com/build-sessions)

## What happens in a session

A connector gets built or sharpened against a live tenant, in the open. You see the messy real-world parts - the auth quirk, the cross-client query that the live API can't answer in one shot, the fix that makes it work - and you can bring your own system and question to work through.

The connectors you install from this site are the same ones built here. If the tool you need isn't covered yet, a Build Session is the fastest way to get it built against a real tenant. [Request a connector →](/requesting-a-skill/) or just show up.

## The free room and the Build Room

The free Thursday session stays free - always. Alongside it, the **Build Room** is the paid deep-work room for MSPs who want to go further between sessions.
